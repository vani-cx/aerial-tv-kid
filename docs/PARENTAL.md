# 儿童模式与时间管理

给户主用的说明，也给接手代码的人看。实现上的取舍和已知漏洞见 [SECURITY-REVIEW.md](SECURITY-REVIEW.md)。

一句话：**锁定的 App 要用「应用锁定密码」（方向密码）才能开；分组里的 App 有每日总时长、每次使用时长、间隔休息和允许时段，到点弹出一张全屏拦截页——页上能答数学题换时长，也能叫家长来用「儿童时间锁密码」放行 10–50 分钟。**

Aerial 自己原来的 4 位家长密码已经删掉了（1.36）。原来被它挡的入口（Aerial 设置、控制中心里的 Wi-Fi 与设置、隐藏 App 面板、以及关掉它自己）现在由**管理员密码**挡。

## 三个密码

| | 管理员密码 | 应用锁定密码 | 儿童时间锁密码 |
|---|---|---|---|
| 形式 | 8 位，字母和数字都必须有 | 遥控器上下左右，4–8 个方向，OK 结束 | 同左 |
| 用来做什么 | 进「儿童与时间管理」、改任何规则、改或删两个方向密码、开电视自带设置 App | 打开被锁定的 App；解除锁定 | 拦截页上点「叫爸爸妈妈来」时验证，之后选 10/20/30/40/50 分钟 |
| 什么时候要 | 每次进「儿童与时间管理」；离开 1 分钟内再进不用输，超过就重输 | 每次打开锁定的 App | 每次要放行时间 |
| 怎么改 | 进面板后直接改，**里面每一项都不再单独问密码** | 进面板后直接改，**儿童模式开不开都行** | 同左；默认就是应用锁定密码那一个 |
| 存法 | PBKDF2-HMAC-SHA1，60000 轮，16 字节随机盐 | 同上（整串方向一起哈希） | 同上 |
| 错几次 | 连错 5 次等 30 秒，再连错 5 次等 1 分钟，然后 2、4、8 分钟 | 同左（三个密码共用同一个等待计数） | 同左 |

三个密码都**不可能找回**：只存哈希。忘了就按下面的「恢复」清掉整个功能。

方向密码是**变长**的：按 4 到 8 个方向，按 OK 就算这一遍输完（不是等某个固定位数）。设置时要连输两遍，一致才保存。

**输入时屏幕只显示圆点**，不显示按了哪些方向；管理员密码同理，只显示 8 个圆点。这样站在后面看的人读不走密码（1.37 起）。

儿童时间锁密码默认跟应用锁定密码**是同一个**（`kid_combo_same`），一户人家只需要记一个方向密码；想分开也可以在设置里单独设一个。

## 从哪里进

首页 → 右上角控制中心 → 个性化（或长按空白处）→ 底部「儿童与时间管理」。

第一次进去要先设管理员密码（两次输入一样、8 位、字母数字都有）。

之后**每次进这个面板都要管理员密码**（`whenKidUnlocked`），只有一处例外：**退出面板不到 1 分钟又进来**不用再输（`Parental.KID_WINDOW_MS = 60 秒`，从「退出」那一刻算，不是从输密码那一刻算——所以在里面待多久都不影响）。回主屏幕（`onHomePressed` → `Parental.closeAdmin()`）、息屏（`WatchService`）都会立刻清掉这个宽限。

**面板里面任何一项都不再单独要密码**：删分组、清今日用量、关儿童模式、改两个方向密码、清管理员密码，点下去就生效。入口那一次验证就是全部的关口，这是户主 1.38 定的规则——代价是：宽限的一分钟里孩子拿到遥控器，也能改这些。

面板里从上到下：

1. **儿童模式** 开/关。关掉后时间规则和计时都不生效，**但应用锁定照样生效**。
2. **计时服务** 状态和「去开启」——跳到系统的无障碍设置页。见下面「计时」。
3. **管理员密码**：设置 / 修改 / 删除。
4. **应用锁定密码**：设置 / 修改 / 删除，过管理员密码就行，**儿童模式关着也能改**（1.38 起；以前这两个按钮在模式关着时不能选，遥控器会直接跳过这两行）。
5. **儿童时间锁密码**：可以单独设一个，也可以选「改用应用锁定密码」共用一个。
6. **儿童年龄** 3–12 岁：决定数学题的难度。
7. **锁定的 App**：勾选。这些 App 打开时要应用锁定密码。
8. **时间限制**：分组列表，每行是「N 个 App · 今天 X 分钟 / 上限」，有放行时会多一句「已放行，剩 N 分钟」，后面是「编辑 / 清零 / 删除」。

## 应用锁定

入口有两个：

- 面板里的「锁定的 App」（多选）。
- **首页长按某个磁贴 → 菜单里的「锁定应用 / 解除锁定」**。

长按菜单那条的行为（需求原文）：

- **不需要开儿童模式**，也不需要管理员密码。锁定是独立的一件事。
- **第一次锁**（还没有应用锁定密码）：直接弹出设置密码的界面，上面写着规则（按 4–8 个方向、连输两遍），并另起一行提示「以后要修改或删除它，输入管理员密码就行」。
- 已经有密码了：按一下就锁上。
- **解除锁定**：一律先验证应用锁定密码（`Overlay.LockConfirm` → `AppUnlockGate`），输对才解除。
- 修改或删除密码：在「儿童与时间管理」里过一遍管理员密码就能做，儿童模式关着也行（1.38 起）。

上锁之后的行为：

- 从 Aerial 点开 → 直接进应用锁定密码盘（`Overlay.KidGate(lockMode = true)`），输对才启动。
- 已经在别处打开了（比如从系统的「最近任务」或厂商桌面进来）→ 无障碍服务看见前台变了，弹 `BlockActivity` 盖住。
- **自动复锁**（`Parental.lockAll` / `lockApp`）：解锁只覆盖「这一次」。回主屏幕、切到别的 App（`onForegroundChanged`）、**息屏/待机**（`ACTION_SCREEN_OFF`）、以及 Aerial 进程重启，都会重新上锁。密码本身不设「打开多少分钟」。
- **例外：家长放行期间退出 App 有 1 分钟缓冲**（`RELOCK_GRACE_MS`）。正在放行（`Usage.passLeftSec > 0`）时按错了 Home、或者切去信号源又切回来，1 分钟内回来不用再输密码；超过 1 分钟就重新上锁。息屏、重启不走这个缓冲，立刻锁。

## 时间限制分组

### 数据

一个分组（`Group`）= 名字 + 一组包 + 7 条日规则（周一在前）。一条日规则（`DayRule`）有四项：

| 项 | 默认 | 0 的含义 | 可选值 |
|---|---|---|---|
| `dailyMinutes` 每日总时长 | 60 | 不限 | 30/60/90/120/180/240/不限 |
| `sessionMinutes` 每次使用时长 | 30 | 不限 | 15/20/30/45/60/90/不限 |
| `breakMinutes` 间隔休息 | 10 | 不休息 | 0/5/10/15/20/30/60 |
| `windows` 允许时段 | 空（全天） | 全天 | 每段起止，±30 分钟调，可加多段 |

`enabled` 是「这一天限制开不开」。日期那一行是**多选**（1.38 起）：点一下选中、再点取消，周一和周二可以同时亮着，下面所有改动（开/关、四项数值、时段增减）会一起落到选中的每一天。「每天」按钮把当前第一条选中日的规则复制到 7 天，并且**把周一到周日全部选中**。

新建分组**不会立刻存**：名字默认是「分组」，标题下面一行提示「还没有保存」，点「完成」才写入；点「取消」或者按返回就直接丢掉（1.38 起；以前一按「新建分组」就存进列表，按返回也留着）。

### 判定顺序（`Parental.verdict`）

每次判断一个包现在能不能用，按这个顺序，**第一个不通过的说了算**：

1. 这个包被锁定且这次还没解锁 → `Locked`（**不受儿童模式开关影响**）。
2. 儿童模式关着 → 放行。
3. 不属于任何分组 → 放行。
4. 生日切了（`Usage.rollDay`）→ 今天的数字清零。
5. 这个组有家长放的时长（`passUntil`）→ 放行。
6. 这一天的限制关着 → 放行。
7. 今天用够了每日总时长 → 拦（`Reason.Daily`，**没有数学题**，只有家长能放）。
8. 数学题买的时段外时长还在（`quizPassUntil`）→ 放行。
9. 不在允许时段里 → 拦（`Reason.Window`，可以答数学题换 15 分钟）。
10. 还在间隔休息里 → 拦（`Reason.Break`，可以答数学题换 5 分钟）。
11. 这一次连续用够了每次使用时长（加上数学题给的 5 分钟）→ 立刻开始休息，拦（`Reason.Break`）。
12. 否则放行。

每日总时长排在同一条线的最前面（第 7 步），所以「今天的额度用完了」永远压过数学题——这是刻意的。

### 什么算「一次使用」

- 打开组里任意一个 App = 开始一次（`Usage.beginSession`）。
- 转到组里**另一个** App 不算中断（还在同一个组）。
- 回到主屏幕、打开别的 App、App 被杀掉 = 这一次结束（`Usage.endSession`）。**撑过 60 秒的一次才算数**，才开始算休息——App 崩了、快速回主屏幕看一眼不该罚孩子。
- 一次使用里答对数学题 = 这一次多 5 分钟（`Session.extraSec`）。

### 休息按墙钟算，进出不打断

这是这一版的关键语义。单次时长用到头的那一刻（`Usage.hitSession`）就把**那一刻**记下来（`Session.hitAt` → `lastEnd`），于是：

- 孩子留在拦截页看着倒计时，时间在走；
- 孩子按「回主屏幕」，时间照走；
- 孩子过 5 分钟再进来，休息已经少了一大截，而不是重新开始；
- 休息到点（`Usage.restLeftSec` 到期）自动开新的「一次」，孩子不用离开 App 就能接着看。

拦截页上的倒计时就是 `restLeftSec` 的秒数，每秒重画一次（`kid_wall_rest_left`）。

### 需求里的四类拦截

拦截页是 `ui/parental/ParentalWall.kt`，全屏、黑底，遥控器只能操作页上的东西，没有「悄悄点过去」的路径（`BlockActivity` 在无障碍服务里被显式忽略，防止它自己被当成前台 App）。

1. **时段外**（`Reason.Window`）：按当前时刻换文案——太早 / 午休（12–13 点）/ 太晚（下一个时段是明天的）/ 还不到点。按钮「答对一道数学题，就能再看一会儿」→ 答对给 **15 分钟**，**每天只有一次**（`Usage.quizExtraUsedToday`，按 `dayKey` 记）。
2. **时段内、这一次到点**（`Reason.Break`）：文案「你已经看很久啦」，下面是**墙钟倒计时**。数学题答对给 **5 分钟**，计入每日总时长的额度（`Session.extraSec`），每次休息可以答一次。
3. **每日总时长用完**（`Reason.Daily`）：文案「今天看够啦」，**没有数学题按钮**，只剩「叫爸爸妈妈来」和「回到首页」。
4. **App 被锁定**（`Verdict.Locked`）：直接进密码盘；返回一步会看到「这个还锁着呢」。

答错一律「你答错了，再想想。」，清空输入框并换一道新题（`answerMath`），可以一直试——这是练习，不是惩罚。答对后先给一句提醒（`kid_wall_note_window` / `kid_wall_note_rest`，2.6 秒），再放行。

**「叫爸爸妈妈来」**先问儿童时间锁密码（`Step.TimeCombo`，没设过就退回管理员密码 `Step.Admin`），验过之后才出 10/20/30/40/50 分钟五个选项（`PassPicker`）。选完就是「挂钟放行」：到点自动收回，期间不受时段、每日总量、单次、休息限制，但**时间照常计入今天的用量**。

页面每秒重新判断一次（`LaunchedEffect` 里的 1 秒循环），条件自己变好（休息结束、时段到了、家长在别处放了行）就自己关掉。

### 数学题的难度

题库在 `ParentalWall.kt` 的 `newQuestion(age)`，按设置里的**儿童年龄**分四档：

| 年龄 | 题目 |
|---|---|
| 3–5 | 10 以内加减 |
| 6–7 | 20 以内加减 |
| 8–9 | 100 以内加减 + 乘法口诀 |
| 10–12 | 两位数加法、除法、形如 `3 × 4 + 5` 的两步运算 |

答案用遥控器数字键或屏幕键盘输入，最多 3 位（最大答案是 89 + 99 = 188）。屏幕键盘是 3 列 4 行：1–9，最后一行是**确认 / 0 / 删除**，每行等宽、整体居中（1.39 起；以前底行是「0 + 一个宽的删除 + 一个宽的确认」，比上面的数字行宽一大截，看着整个键盘往左歪）。

**按「确认」才提交**：遥控器 OK 键交给屏幕上的方块处理，主机只在前置阶段接管数字键和删除键。1.39 之前主机把 OK 也接管了——它在焦点系统之前跑，于是按在数字上的 OK 变成了「提交空答案框」，屏幕上直接显示「你答错了」，数字根本没进去。

### 家长加时长的语义

`Usage.grantPass(groupId, minutes)` 记的是「到这个时刻为止放行」，不是「加多少分钟额度」。好处是加完之后哪怕孩子立刻回主屏幕、过 20 分钟再来，那 20 分钟也算在放行里——和家长的直觉一致，也不会因为反复进出而多送时间。多个 pass 会累加。

## 计时

这是整个功能里唯一有真实工程约束的地方。

Aerial 自己就是桌面：孩子打开爱奇艺之后，Aerial 的进程就不在前台了，靠 Aerial 自己数时间是数不到的。所以照 [tvwall](https://github.com/iBala/tvwall) 的做法，用一个**无障碍服务**（`WatchService`）：

- 只订阅 `typeWindowStateChanged`，`canRetrieveWindowContent="false"`——只要知道「前台是哪个包」，不读屏幕内容（见 `res/xml/parental_watch.xml`）。
- 每 5 秒（`TICK_MS`）把这段时间加到当前前台的组上，**只在 `PowerManager.isInteractive` 为真时加**：待机、黑屏不算。
- 两次 tick 之间超过 15 秒（`MAX_GAP_MS`）= 电视睡过去了，这一整段不算。
- 拦截页显示着的时候不计数（`BlockActivity.isShowing`）。
- 只把真正的 Activity 当成前台（`isActivity` 用 `PackageManager.getActivityInfo` 判断），弹窗、Toast 不算；Aerial 自己的窗口算「主屏幕」，拦截页除外。
- 到点由这个服务直接拉起 `BlockActivity`——无障碍服务是少数能在后台启动 Activity 的组件，这也是必须用它的原因。

**没开启无障碍服务时**还有一层降级（`FallbackClock`）：Aerial 打开组里的 App 时自己起一个同样的 5 秒计时，回主屏幕时停。它只覆盖「从 Aerial 打开、再回 Aerial」这一条路；从别处打开的 App 拦不到。设置面板里那个「计时服务：未开启」就是这个意思——**要用完整功能必须让「Aerial 儿童计时」出现在无障碍列表里**。用 `install.sh` 或照 README 授过 `WRITE_SECURE_SETTINGS` 的话，在面板里把儿童模式打开时 Aerial 会自己写进去（`GuardSetup.ensureWatch`），不用手动去系统设置；没有这个权限时才需要手动开，见下一节。

### 用 ADB 开启计时服务

无障碍**不是可以用 `pm grant` 授权的权限**，只有两条路：电视上手动开，或者直接写系统设置。遥控器不方便时用后者：

```bash
# 先看现在开着哪些，多个服务用冒号分隔，别把别人的覆盖掉
adb shell settings get secure enabled_accessibility_services

# 只有这一个服务时
adb shell settings put secure enabled_accessibility_services \
  com.vani.aerialkid/app.orchard.tv.parental.WatchService
adb shell settings put secure accessibility_enabled 1

# 已经有别的服务时，把新的接在后面
adb shell settings put secure enabled_accessibility_services \
  "com.example.other/com.example.other.Service:com.vani.aerialkid/app.orchard.tv.parental.WatchService"
```

> **有的固件把这条路封死了。** 坚果 N1（S700）的 `SettingsProvider` 直接拒绝第三方写 `enabled_accessibility_services`（连写回原值都拒），系统里也没有无障碍设置页，`adb root` 也不可用——那台机器上只能用降级计时。它唯一还拿得到的相关权限是 `appops set com.vani.aerialkid GET_USAGE_STATS allow`（系统自己记着哪个 App 何时在前台、屏幕何时亮着），细节见 [docs/devices/jmgo-n1.md](devices/jmgo-n1.md)。

改完回设置面板看「计时服务」是不是「已开启」。**这一步只做一次**：写进的是系统的 `secure` 设置，重启、待机都不会自己丢。丢的情况只有三种——卸载重装（设置跟着包走）、恢复出厂，以及被固件「强行停止」（见下）。

### 被固件关掉之后

Android 有一条规则：应用被**强行停止**时，它的无障碍服务会从列表里删掉。小米在待机时强停所有第三方 App，所以这个列表是会掉的——这也是 tvwall 那类方案共同的软肋。

Aerial 的补法是 `GuardSetup`：`ensureEnabled()` 在开机（`BootReceiver`）、`MainActivity` 启动、通知监听复活时都会跑，发现儿童模式开着而服务不在列表里就写回去（`ensureHome` / `ensureWatch`），同时把 `accessibility_enabled` 置 1。所以家用场景下不用重跑 ADB 命令。`rebindIfStalled()` 另外照顾「在列表里但没绑上」的情况（TCL 升级 APK 后见过），会把服务摘掉再放回去，逼系统重新绑定。

代价要说清楚：**儿童模式开着时，Aerial 会把自己加回无障碍列表**。在系统设置里手动关掉，下次 Aerial 启动还会被恢复——这是刻意的，否则孩子按两下就能废掉时间限制。真要关，走面板里的「关」（需要管理员密码），它会同时把服务从列表里摘掉（`releaseWatch`）；或者用 `clear_kid`。

Android 13 起，侧载应用的开关在「设置 → 无障碍」里可能是灰的，要先在「应用信息」里「允许受限设置」。ADB 写设置一般不受这个限制，但个别国产固件会拦。

## 数据放在哪

| SharedPreferences | 键 | 内容 |
|---|---|---|
| `parental` | `admin_hash` `app_combo_hash` `app_combo_len` `kid_combo_hash` `kid_combo_len` `kid_combo_same` `child_age` `enabled` `locked` `groups` `fails` `lockouts` `blocked_until` | 三个密码的哈希、开关、年龄、锁定集合、分组 JSON |
| `parental_usage` | `day` `used` `pass` `quiz_pass` `quiz_day` `sessions` `lastEnd` `rest_cap` `rest_quiz` | 当天的秒数、放行截止时刻、数学题买的时间、进行中的一次、上次结束时刻 |

`parental_usage` 里所有东西都按**本地日期**滚动：日期变了就整体清空（`Usage.rollDay`）。所以跨零点会清零，改电视的日期也会清零——这是刻意的（见 SECURITY-REVIEW 的 K-6）。

1.35 及更早只有一个 `combo_hash` / `combo_len`，1.36 启动时（`Parental.init`）把它复制成应用锁定密码和时间锁密码两把，然后删掉旧键。

## 恢复：忘了密码

密码只有哈希，救不回来。用电脑：

```bash
adb shell am broadcast -a app.orchard.tv.CONFIG -n com.vani.aerialkid/app.orchard.tv.guard.ConfigReceiver --ez clear_kid true
```

这条会：关掉儿童模式、删掉管理员密码和两个方向密码、清空锁定列表、删掉所有分组（用量一起清）。这个广播要求发送方持有 `WRITE_SECURE_SETTINGS`，普通 App 拿不到，只有 ADB shell 能发（见 `guard/ConfigReceiver.kt`）。

只想重来一天（比如电视时间被调乱了），在分组那一行按「清零」即可。

## 真机测试清单

改动没在真机上跑过之前，下面这些至少过一遍（小米 MiTV-MFTR0 或 TCL MT5879 都行）：

1. 设管理员密码（8 位、字母数字都要有）：格式不对要给提示；两次不一样要重来。
2. **没开儿童模式**时：长按一个 App → 锁定应用 → 弹出设置密码 → 连输两遍 → App 上锁 → 点它要密码 → 输对能开 → 回主屏幕再点，又要密码。
3. 息屏 5 秒再唤醒 → 再点那个 App，仍然要密码。
4. 长按已锁的 App → 解除锁定 → 先要方向密码 → 输对才解开。
5. **没开儿童模式**时，设置面板里的应用锁定密码「修改 / 删除」应该是灰的。
6. 开儿童模式，单独设一个时间锁密码；拦截面点「叫爸爸妈妈来」→ 先问这个密码 → 再出 10/20/30/40/50。
7. 建一个分组，只放一个 App，每日总时长 30、每次 15、休息 5，今天这一天开。
8. 看满 15 分钟 → 「你已经看很久啦」+ 倒计时 → 答对数学题 → 提醒 → 又能看 5 分钟。
9. 到点的瞬间按 HOME，等 3 分钟再进来 → 倒计时应该少了 3 分钟，不是重新开始。
10. 休息到点留在 App 里 → 应该自己恢复，不用退出。
11. 每日总时长临时设成 5 分钟 → 看满 → 只有「叫爸爸妈妈来」和「回到首页」，没有数学题。
12. 允许时段设成 5 分钟后开始 → 现在就打不开，提示「再等一会儿」；把时段设成明天 → 提示「该睡觉啦」。
13. 时段外答对数学题 → 提醒 15 分钟 → 能看；同一天再拦 → 没有数学题按钮。
14. 答错的题 → 「你答错了，再想想」，输入框清空，题目换了。
15. 把儿童年龄从 4 调到 11 → 数学题明显变难（乘除、两步运算）。
16. 中途关掉无障碍服务 → 设置面板显示「未开启」，从首页打开仍然拦截（降级计时）。
17. 打开电视自带设置 App（或控制中心里那个）→ 应该先要管理员密码。
18. 待机 10 分钟再唤醒 → 用量不应该增加 10 分钟。
19. 跨零点：把日期改到明天 → 今天用的分钟数清零。
20. `clear_kid` 广播 → 全部回到初始状态。
21. 旧版升级：原来设过方向密码的电视，升级后那个密码同时是应用锁定密码和时间锁密码；原来设过 4 位家长密码的电视，那个密码不再被问，改成问管理员密码。
22. 输密码时盯着屏幕：方向密码和管理员密码都只出现**圆点**，看不出按了什么。
23. 请家长放行 10 分钟 → 打开被锁的 App → 按 Home → 立刻再打开：1 分钟内**不用**再输密码。
24. 同样的情况等 1 分钟以上再打开 → 要重新输方向密码。
25. 同样的情况按一下电源键息屏再开 → 立刻要密码（不走缓冲）。
26. 儿童模式**关着**时，在设置里用遥控器上下走一遍：应用锁定密码、儿童时间锁密码这两行的按钮都要**能被选中**（1.38 前会被跳过），点进去过管理员密码就能改。
27. 分组编辑：点「周二」再点「周三」，两天一起亮；这时改「每日总时长」，两天一起变。点「每天」→ 周一到周日全亮，规则一致。
28. 点「新建分组」→ 改个名字 → 直接按返回 → 回到列表，**没有多出分组**。再来一次，这次点「完成」→ 分组出现在列表里。
29. 退出面板后 30 秒内再进 → 不再问密码；等 1 分半再进 → 要重新输。按 Home 回主屏幕后马上进 → 要重输。
30. 进面板之后每个子项都不再问密码：点「删除分组」「清零」「关儿童模式」「改应用锁定密码」都直接生效（入口那一次已经验证过）。
31. 管理员密码框留空直接按返回 → 只关掉密码框，**还停在主屏幕**，不会跳去别的页面。
32. 拦截页上点「答对一道数学题」→ 用遥控器 OK 键**点数字**：数字要进答案框，**不能**一闪变成「你答错了」。输完按「确认」→ 答对给时长，答错换一道新题。
33. 键盘是 3 列 4 行：1–9，最后一行**确认 / 0 / 删除**，每行等宽、整体居中；方块够大，坐着看得清。
34. 拦截页和设置面板里的提示小字（每组规则下面那行灰字、密码框下面的说明）要能在常看的距离上读出来（1.39 起从 11sp 提到 15 / 17sp）。
